# Student Marks Analysis

A Python data analysis project using Pandas to analyze student marks and generate useful statistics.

## Project Description

This project analyzes student marks using Python and Pandas. It calculates average marks, identifies the highest and lowest marks, assigns grades, and creates a CSV file for storing the results.

## Features

- Calculate average marks
- Find highest marks
- Find lowest marks
- Assign grades to students
- Display student results
- Create and save CSV data

## Technologies Used

- Python
- Pandas
- CSV

## Sample Results

| Student | Marks | Grade |
|---|---:|---|
| Ali | 80 | A |
| Sara | 90 | A+ |
| Ahmed | 75 | B |
| Ayesha | 95 | A+ |
| Bilal | 70 | B |

## Analysis

- Highest Marks: 95
- Lowest Marks: 70
- Average Marks: 82
